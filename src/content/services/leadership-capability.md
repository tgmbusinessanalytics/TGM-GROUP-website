There is a size at which an organisation stops being able to run on the founder's
judgement. It is usually reached before anybody notices, and the symptom is a
leadership team that is busy but not deciding.

The work starts with decision rights: which decisions are being made at which
level, which ones are escalating that should not, and which are being avoided
altogether. That is a structural question more often than a personnel one.
Managers escalate by default when it has never been made explicit what they are
allowed to decide alone.

From there it is practical capability. How to run a meeting that ends in
decisions. How to give feedback that changes something. How to hold a number
without micromanaging the person holding it. How to hire for a role you have
never done yourself.

We also look at concentration risk honestly — the roles where one person's
resignation would cost the organisation months, and what to do about that before
it happens rather than during.

This work sits with **TGM Business Services** and is often the phase-four work
that makes everything else hold.
